# 狮山实达数据统计 · 使用与部署说明

手机网页版 App（PWA），iOS / 安卓通用。手机浏览器打开网址 →「添加到主屏幕」，就有独立图标、全屏启动、离线可开。

## 两种账号

| 账号 | 密码 | 能做什么 |
|---|---|---|
| 管理员 `sclh` | `sclh2026` | 编辑球队资料、增删球员、增删场地、增删赛程、连接云端、导出备份 |
| 录入员 `luru` | `sssd2026` | **只能进「录入」页**，录入比赛日期、场地、对手、比分、进球与助攻 |

未登录时为**只读模式**，任何人都能随时查看赛程、榜单、球员。

> 两个账号密码都在 `js/config.js` 里，可随时改。

## 一、录入员怎么用（每次比赛后 1 分钟搞定）

用录入员账号登录后，底部导航会出现 **📝 录入** 页，直接就是一张表单：

```
比赛日期   [日期时间选择器]
场地       [下拉，选管理员建好的场地]
对手       [填队名]
比分       我方 [0] : 对手 [0]

进球   [球员下拉] [几球]   ← 可点「＋添加进球球员」加多人
助攻   [球员下拉] [几次]   ← 可点「＋添加助攻球员」加多人

        [✓ 保存这场比赛]
```

保存后：
- 这场比赛自动标记为**已结束**，进入赛程
- 进球、助攻自动汇总进射手榜 / 助攻榜
- 首页的已赛、积分、净胜球、胜率、近况小球全部自动更新
- 页面下方「最近录入」能看到刚录的场次，点开可查看详情；**录错了可以删除自己录的那场**

几个细节：
- **出场不用录**：某球员只要在这场比赛里有进球、助攻中任意一项，就自动计 1 次出场
- 球员名单由管理员维护，录入员不能新增（如需加人找管理员）
- 进球数填 0 或者没填球员也能保存（会二次确认）

## 二、管理员要做的（只做一次）

1. **球员**页：把队员加进去（姓名、号码、位置）— 这是录入的前提
2. **场地**页：把常用球场加进去（名称、地址、价格）
3. **球队介绍**：改队名、口号、主场、简介
4. **连云端**（见下）

### 球员信息卡（星光动效 + 全身照）

点球员列表里任意一人，弹出信息卡：

**动效（A 方案，纯 CSS，手机上 60 帧）**
- 全身照从下方弹跳入场
- 背后柔光呼吸缩放、脚下光环脉动
- 12 个光点环绕缓慢旋转，各自独立闪烁（金 / 白 / 蓝三色交错）
- 姓名、徽标、数据区块依次错峰淡入
- 自动尊重系统的「减少动效」设置，开了就不再播动画

**全身照怎么来的**
不是 AI 生成，是**本地 Canvas 合成**：把你上传的**头像**裁剪成圆形贴在头部，
其余身体（球衣 / 号码 / 球裤 / 球袜 / 球鞋）由代码按队色绘制。
所以只要给球员填了头像，选中球衣款式就自动出全身图。

**4 种球衣款式**可实时切换（切换立即重绘，不用重新上传）：

| 款式 | 上衣 | 号码 | 球裤 |
|---|---|---|---|
| 主场 | 深蓝 | 金 | 深蓝 |
| 客场 | 白 | 深蓝 | 白 |
| 门将 | 金 | 深蓝 | 黑 |
| 训练 | 灰 | 白 | 深蓝 |

> 头像填写位置：管理员 → 球员 → 编辑 →「头像图片地址」。
> 没填头像时，头部显示球员姓名首字。

**近 5 场表现**：取该球员**实际出场**的最近 5 场（有进球/助攻/射门/牌任一项即算出场），
显示日期、对手、该场进球/助攻/黄红牌，左侧色条表示球队该场胜负（绿胜 / 灰平 / 红负）。

## 四、部署上线（约 10 分钟，免费）

### 方式 A：不连云端，单机先用（1 分钟）
把 `sclh-app` 整个文件夹丢进任意静态托管（Cloudflare Pages / Netlify / Vercel / 腾讯云 COS）。
此时数据存在各自手机本机，适合先试用。

### 方式 B：连云端，全队共用一份数据（推荐）
不用改代码，全程在网页里点几下。

**第 1 步：建表（只做一次）**
1. Supabase 控制台 → 打开项目 → 左侧 **SQL Editor** → **New query**
2. 把 `supabase/schema.sql` 全文粘贴进去 → **Run**
3. 出现绿色 `Success. No rows returned` 即成功（脚本可重复执行）

**第 2 步：拿 URL 和 Key**
- 左下角齿轮 **Settings → API**（新版叫 **API Keys**）
- **Project URL**：`https://abcdefgh.supabase.co`（**不要**复制 Data API 页里带 `/rest/v1/` 的那串）
- **API Keys**：复制 **publishable**（`sb_publishable_` 开头）或 **anon public**（`eyJhbGciOi` 开头）
- ⚠️ **别复制 `service_role` / `sb_secret_` 开头的**，那是管理员密钥

**第 3 步：填进 App**
⚙️ → 用管理员登录 → **☁️ 连接云端数据库** → 粘贴 → **连接并保存**。
顶部标签变「云端已连接」即成功。

**第 4 步：发给队友**
⚙️ → **☁️ 云端设置 / 生成分享链接** → 复制发到球队群，队友点开自动连同一个库。
（之前本机录过数据的话，页面里有「把本机 N 条数据上传到云端」按钮，一次搬过去。）

> 免费项目 7 天无人访问会自动暂停，去后台点 Restore 恢复即可。
> 免费额度：数据库 500 MB、文件 1 GB、月流量约 10 GB —— 一支业余球队用不完。

### 安装到手机桌面
- **iPhone**：Safari 打开 → 底部分享 →「添加到主屏幕」
- **安卓**：Chrome 打开 → 右上角菜单 →「添加到主屏幕」
- 站内：⚙️ → 登录 →「安装到桌面」

## 五、常见问题

### 保存失败：Could not find the 'xxx' column
**原因**：云端表缺少新版才加的字段（`competition`、`created_by`、`is_penalty` 等）。老项目升级时容易遇到。

**最快修法**：Supabase → **SQL Editor** → 打开 `import/一键修复表结构.sql` → 全文粘贴 → **Run**。
这个文件会把 5 张表的所有列一次性补齐（已存在的自动跳过，**不丢任何数据**），末尾还带 `notify pgrst, 'reload schema';`。

只想手动跑关键几句也行，但**最后那句刷新缓存必须跑**：
```sql
alter table public.matches add column if not exists competition text;
alter table public.matches add column if not exists created_by  text;
alter table public.events  add column if not exists is_penalty  boolean default false;
notify pgrst, 'reload schema';
```
> Supabase 会缓存表结构，不刷新缓存即使加了列仍报同样的错——这是最常见的坑。

> 排查：⚙️ → 管理员登录 → **🔧 检查云端表结构**，会自动列出缺哪些列并生成可复制的 SQL。
> 兜底：万一某列真没有，App 会自动丢掉该列、把其余字段存进去，不会整条丢失（赛事类型留空，之后在比赛详情补）。

### 历史数据怎么批量导入
Excel 里的历史战绩不用手敲。用 `tools/gen-import.js` 生成 SQL，到 Supabase 跑一次即可（详见下方「导入历史战绩」）。

## 导入历史战绩（Excel → 云端）

已在 `import/历史战绩导入.sql` 里预置好 41 场历史比赛 + 7 个场地，直接可用。

**用法**：Supabase → SQL Editor → 打开该文件 → 全文粘贴 → **Run**。

**结果**：40 战 30 胜 3 平 7 负，进 251 失 167，净胜 84，积分 93，胜率 75%。

| 项目 | 说明 |
|---|---|
| 场地 | 弘艺、桂花园、华涌、崇北、南体、丹邱、昱朗（自动建） |
| 赛季 | 全部归入 `2026` |
| 赛事 | 全部标记为**友谊赛**（如需改，见下） |
| 场次 | 第 1 场 ~ 第 41 场（写进「轮次」列） |
| 时间 | 原表只有日期，统一补 `19:30` |
| 第 17 场 | 原表比分为 `-`，导入为**未开始**状态 |
| 第 24 场 | 备注「实达客家联队」已保留 |

**脚本安全**：开头会先删除 `created_by='import'` 的旧数据再插入，**重复执行不会产生重复记录**，且不会动你手工录入的内容。

**想改默认值的**，编辑 `tools/gen-import.js` 顶部三行后重跑 `node tools/gen-import.js`：
```js
const SEASON = '2026';       // 赛季
const COMP   = '友谊赛';      // 赛事类型：联赛 / 杯赛 / 友谊赛 / 内部赛
const KICKOFF= '19:30';      // 开球时间
```

> ⚠️ 历史导入**不含进球/助攻球员**（原表没有），所以射手榜、助攻榜是空的。
> 只有从现在开始用「录入」页录的比赛，才会自动汇总出榜单数据。

**备选方案**（本机模式或不想跑 SQL）：管理后台 →「📥 导入备份」→ 选 `import/狮山实达历史数据.json`。

### 队友打不开 / 显示 403
- **Netlify**：站点还是私有。去 `app.netlify.com` → 进站点 → **Make public**（或 Site configuration → Project visibility → Public）。用**手机浏览器**验证才算数——电脑登录着 Netlify 会误以为成功。
- **Cloudflare Pages**：默认就是公开的，出现 403 多半是文件夹层级传错（传了外套的 `sclh-app` 文件夹，导致根目录没有 `index.html`）。

### 网址带一串乱码（xxx--yyy.netlify.app）
那是**部署预览地址**，队友打不开。正式地址去掉 `--` 及前面的随机串：
`6ac8686--velvety-marzipan.netlify.app` → `velvety-marzipan.netlify.app`

### 一键截图没有背景 / 截出来是空白
已修复。旧版用 `html2canvas` 抓取 DOM，它不支持 CSS 变量、`linear-gradient`、伪元素，常常整块背景丢失。
新版改为 **`js/poster.js` + 原生 Canvas 逐块绘制**：背景、深蓝渐变卡片、金色数据、圆角、头像全部手绘，结果稳定且更清晰（输出 1500px 宽 2 倍图）。

> 如果仍异常：确认浏览器没屏蔽 Canvas（极少数隐私模式会），或先**关掉页面重开**让离线缓存更新。

### 数据只在一台设备上
顶部标签显示「本机模式」= 还没连云端。⚙️ → 管理员登录 → **☁️ 连接云端数据库**。

### 免费项目被暂停
7 天无人访问会自动暂停，进 Supabase 后台点 **Restore** 恢复，数据不丢。
